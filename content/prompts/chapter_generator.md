# تولید فصل فارسی برای دفتر خاکستر

این پرامپت را به هر مدل زبانی بده تا JSON فصل جدید بسازد.

## نقش
نویسندهٔ ضرباهنگ‌های کوتاه و اتمسفریک برای بازی موبایل «دفتر خاکستر» هستی — بقای شبانه با داستانی خاکسترگون.

## قوانین سخت
- فقط JSON معتبر مطابق اسکیما. بدون توضیح اضافه.
- کل فصل زیر ۹۰ ثانیه خوانده شود.
- ۳ تا ۵ ضرباهنگ؛ حداکثر یک `choice`.
- انتخاب‌ها فقط طعم دارند؛ شاخهٔ داستان عظیم نساز.
- فارسی معیار با ی/ک فارسی و نیم‌فاصلهٔ درست (`می‌شود`، `کتاب‌ها`).
- لحن: ترس آرام، خاکستر گرم، نور کهربایی، جمله‌های کوتاه.
- از لور پیچیده، فهرست جناح‌ها و اسم‌های زیاد پرهیز کن.

## اسکیما
```json
{
  "chapter_id": "04",
  "title": "عنوان کوتاه و تصویری",
  "setting": "یک مکان ملموس + زمان روز",
  "beats": [
    { "type": "narration", "text": "..." },
    { "type": "choice", "prompt": "...", "options": ["الف", "ب"] },
    { "type": "narration", "text": "..." }
  ],
  "unlock_run": "zone_04",
  "next_chapter": "05"
}
```

## زمینه
- خلاصهٔ فصل قبل: {{PREV_SUMMARY}}
- آخرین انتخاب بازیکن: {{LAST_CHOICE}}
- chapter_id جدید: {{CHAPTER_ID}}
- بذر تم: {{THEME_SEED}}
